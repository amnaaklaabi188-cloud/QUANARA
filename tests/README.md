# Tests

Automated checks for data, features, models, scenarios and application pages.

- [`conftest.py`](conftest.py) — Test fixtures and shared setup. · [`test_audit_quality.py`](test_audit_quality.py) — Checks added in the end-to-end audit: one model identity everywhere, simulator eligibility that is actually executable, honest algorithm lists, reproducible Judges' Demo, and no hard-coded data figures.
- [`test_correlation_lab.py`](test_correlation_lab.py) — Section 4 — Correlation & Visualization Lab: statistics reproduced independently from the raw workbooks. · [`test_data.py`](test_data.py) — Data loading, schema validation and cleaning — checked against the real supplied files.
- [`test_data_intel.py`](test_data_intel.py) — Page 2 (Data Intelligence) facts, model-card consistency, and the independent verification. · [`test_feature_engineering.py`](test_feature_engineering.py) — Section 3 — Feature Engineering: facts, scenario sensitivity, matrix identity and the selection flow.
- [`test_integration_features.py`](test_integration_features.py) — Analytical dataset integrity and feature construction (no look-ahead, correct aggregation). · [`test_legacy_artifacts.py`](test_legacy_artifacts.py) — The package rename leaves every saved model usable: each pickled pipeline loads unchanged through the legacy-name alias and reproduces its saved holdout predictions exactly.
- [`test_model_evaluation.py`](test_model_evaluation.py) — Section 6 — Model Evaluation: integrity checks, diagnostics, insights and importance on saved artifacts. · [`test_models_training.py`](test_models_training.py) — Metrics, model factory and the chronological training protocol.
- [`test_overview.py`](test_overview.py) — Page 1 (Welcome & Overview): every displayed fact is computed, the model card follows the active model, the hero animates (with a reduced-motion fallback) and the buttons exist. · [`test_scenario.py`](test_scenario.py) — What-if engine: consistency, no double counting, no silent no-ops, and rejection of invalid input.
- [`test_simulator.py`](test_simulator.py) — Section 7 — What-if Simulator: the redesigned page reports real model predictions, every control moves the intended inputs, sensitivity re-predicts with the saved model, and the scenario record matches the run. · [`test_training_studio.py`](test_training_studio.py) — Section 5 — ML Training Studio: algorithms, constraints, policies, persistence and comparison rules.
- [`test_ui_pages.py`](test_ui_pages.py) — Headless smoke test of every UI section with Streamlit's AppTest (uses the saved reference models).
