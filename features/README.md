# Features

Feature definitions, model-matrix construction and executable feature checks.

- [`build_features.py`](build_features.py) — Build the model matrix for one prediction scope and mode with the application's own feature code.
- [`feature_definitions.csv`](feature_definitions.csv) — Feature catalogue: sources, formulas, windows, missingness and leakage.
- [`feature_validation.py`](feature_validation.py) — Executable checks on the feature pipeline.
